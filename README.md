### Research background

My dissertation investigated **combining changepoint detection with machine learning for anomaly detection in financial time series**.

I explored whether identifying market regimes before applying anomaly detection could improve on a single global model. The project included a reproducible Python experiment pipeline, synthetic and real financial data, and methods including **PELT, Isolation Forest, and Local Outlier Factor**.
